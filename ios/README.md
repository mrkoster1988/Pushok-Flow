# Pushok Flow для iPhone

На главной кнопка «Подключить» запускает существующий профиль или выдачу через Pushok Shop. При входе Flow открывает Telegram, ждёт подтверждения и получает WireGuard через одноразовый билет. Когда Telegram отсутствует, Flow запрашивает гостевую подписку на семь суток. Если Telegram не выходит на связь, гостевой доступ доступен во время ожидания. Срок определяет Shop.

В настройках доступны аккаунт и баланс, обновление подписки, выбор сервера при наличии нескольких, переход в Shop и импорт файла, ссылки Pushok или QR из камеры и фото. На главной отображаются счётчики туннеля, последняя дата handshake и время установки TCP-соединения с pushok.shop. Кнопка MTProxy открывает Telegram и скрывается после ручного подтверждения. Секреты остаются в связке ключей. После выхода с iPhone удаляется профиль текущего аккаунта.

Персональный iPhone использует маршруты WireGuard из профиля. Выбор отдельных приложений средствами Per-App VPN доступен на управляемых устройствах.

## Сборка на Mac

Установите Xcode с iOS SDK, XcodeGen и Go 1.19.13 для сборки моста официального WireGuard Apple 1.0.16-27. Выполните из корня репозитория:

```sh
bash ios/prepare.sh
open ios/PushokFlow.xcodeproj
```

Для обеих целей выберите одну Apple Developer Team. Параметр FLOW_APP_ID задаёт базовый Bundle ID. На обеих целях нужны Network Extensions (Packet Tunnel) и Keychain Sharing с общей группой. Выберите зарегистрированный iPhone и нажмите Run. При импорте первого профиля подтвердите системный запрос на добавление конфигурации. Для установки через TestFlight требуется отдельно подписать и загрузить архив в App Store Connect.

GitHub Actions собирает архив arm64 для физического устройства без подписи и проверяет наличие расширения PacketTunnel. Подключение к серверу и передачу трафика проверяют на подписанном устройстве.
