# Pushok Flow для iPhone

Первый клиент для iOS 16 и новее импортирует один файл WireGuard из «Файлов», сохраняет его в общей связке ключей приложения и расширения и управляет туннелем через Network Extension. Главный экран показывает состояние системного туннеля. В Shop можно перейти по ссылке. Для замены профиля отключите активное соединение.

## Сборка на Mac

Установите Xcode с iOS SDK, XcodeGen и Go 1.19.13 для сборки моста официального WireGuard Apple 1.0.16-27. Выполните из корня репозитория:

```sh
bash ios/prepare.sh
open ios/PushokFlow.xcodeproj
```

Для обеих целей выберите одну Apple Developer Team. Параметр FLOW_APP_ID задаёт базовый Bundle ID. На обеих целях нужны Network Extensions (Packet Tunnel) и Keychain Sharing с общей группой. Выберите зарегистрированный iPhone и нажмите Run. При импорте первого профиля подтвердите системный запрос на добавление конфигурации. Для установки через TestFlight требуется отдельно подписать и загрузить архив в App Store Connect.

GitHub Actions собирает архив arm64 для физического устройства без подписи и проверяет наличие расширения PacketTunnel. Подключение к серверу и передачу трафика проверяют на подписанном устройстве.
