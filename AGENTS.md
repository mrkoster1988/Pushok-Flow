# Pushok Flow

Этот репозиторий относится к проекту Flow. Пользовательское название приложения — **Pushok Flow**, встроенного помощника — **Pushok ИИ**.

## Единая точка входа Pushok

22.11.2026 пользователь закрепил **https://t.me/pushok_app** (`@pushok_app`) как главную ссылку всей экосистемы Pushok. Позднее в тот же день уточнил: за этой ссылкой регистрация ещё не разработана, а действующая регистрация уже есть в проекте MTProxy Pushok. Для аккаунта переиспользовать существующий кабинет MTProxy; не создавать отдельного бота или вторую базу пользователей Flow. `@pushok_app` сохраняется как общая ссылка проекта.

Публичная конфигурация действующего `https://pushok.shop/api/v1/public-config` проверена при подготовке v0.43.0 и указывает на `@mtproxy_pushok_bot`. Кнопка аккаунта открывает этот бот через Telegram, а при отсутствии обработчика — веб-кабинет `https://pushok.shop/`. Открытие кабинета не означает вход внутри Flow: обмена сессией между кабинетом и APK пока нет. Не утверждать, что аккаунт MTProxy сам выдаёт VLESS/WireGuard-подписку или подтверждает оплату Flow. При смене точки входа сверять действующую конфигурацию, а не полагаться только на `.env.example` другого проекта.

## Публикация готовых обновлений

22.11.2026 пользователь явно разрешил публичный выпуск v0.38.0 и поручил всегда публиковать последующие готовые обновления Pushok Flow. Это постоянное указание для дальнейшей разработки данного репозитория: после подготовки и успешных обязательных проверок выпускать обновление в GitHub Releases и канал обновлений приложения без повторного вопроса о публикации.

Сохранять существующий порядок выпуска: успешный CI точного коммита, постоянный сертификат, проверенный APK, SHA-256 и `update.json`, штатный workflow `publish-public-release.yml`. Не менять ключ подписи и не обходить проверки готовности ради публикации.

После выпуска проверять публичное обнаружение версии, оба пути получения манифеста и полное скачивание APK без авторизации; фиксировать реальные результаты в `docs/release-checks/`. Публикация не подтверждает приёмку на физическом телефоне.
