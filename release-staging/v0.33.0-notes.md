Pushok Flow 0.33.0 — понятная диагностика исключений приложений.

### Изменения

- Адресная проверка доступности каждого сохранённого исключения через Android; отсутствие ярлыка приложения само по себе не считается удалением.
- В «Маршрутах» появились фильтр «Недоступные» и пометки приложений, доступность которых Android не подтвердил для Pushok Flow. Старые сведения явно обозначаются как результат последней проверки.
- Перед новым подключением исключения проверяются повторно. Ошибка предлагает открыть «Маршруты»; убрать конкретное исключение можно обычным переключателем. Остальной выбор сохраняется.
- Неизвестное состояние туннеля по-прежнему блокирует новое подключение. Повторное подключение к уже работающему туннелю не перенастраивает его; отключение не зависит от доступности исключённых приложений.
- Проверка публикации дольше ждёт обновления общего адреса GitHub и продолжает требовать точного совпадения файла. Отказ доступа и ограничение частоты не вызывают немедленные повторы.

### Обновление

Профиль → Версия и обновления → Проверить обновления → Скачать → Установить обновление.

Пакет shop.pushok.flow и постоянный сертификат сохранены. Выпуск предназначен для установки поверх предыдущей опубликованной версии.

### Границы

На физическом Android ещё нужно проверить обновление с сохранением данных, удаление и повторную установку выбранного тестового приложения, реальное подключение, DNS и прямые маршруты. Проверка доступности относится к текущему Android-профилю и моменту запроса; она не доказывает, что приложение удалено. Предупреждение Play Protect остаётся отдельной нерешённой задачей.
