### Границы проверки

Состояние опубликованного выпуска проверяется по доступным ответам сервера; одновременное обновление всех узлов GitHub не гарантируется. Время проверки и несохранённые сведения об обнаруженной версии относятся к текущему процессу; готовый APK восстанавливается и проверяется после перезапуска.

На телефоне ещё нужно подтвердить обновление с сохранением данных, поведение при сворачивании и ошибки сети. Реальный WireGuard, DNS/IPv4/IPv6 и прямой трафик выбранных приложений остаются отдельной приёмкой. Ранее наблюдавшееся предупреждение Play Protect и обращение в Google остаются открытыми; этот выпуск не объявляется их исправлением.
