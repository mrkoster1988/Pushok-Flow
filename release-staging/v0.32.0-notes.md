# Pushok Flow 0.32.0 — подключение и профили

- Новое подключение ждёт актуального состояния туннеля после открытия приложения и возврата из фона. Раннее нажатие не перезапускает уже работающий туннель и не теряет открытие редактора при отсутствии профиля.
- Повторный запрос подключения при подтверждённом включённом туннеле не применяет конфигурацию заново и не сбрасывает время сеанса.
- Ошибка подключения или чтения статуса больше не подменяется выключенным состоянием. При последнем известном включённом туннеле остаётся доступно явное отключение.
- Экземпляры Android Activity используют общую очередь операций: устаревшее чтение не выполняется параллельно с новым подключением.
- Исправлены WireGuard-профили с комментариями после `[Interface]` и `[Peer]`. Исключения добавляются в правильный раздел; DNS, AllowedIPs и ключевые строки сохраняются.
- Неподдерживаемые параметры маршрутизации проверяются до сохранения профиля. Сам профиль сохраняется в исходном виде.

Проверки кода: **141 Python, 165 Flutter, восемь исполняемых наборов Kotlin**, анализ Dart без замечаний. Точный источник APK: `c745556a8ac1427527181f546a5386b2a3312a78`. [Source checks](https://github.com/mrkoster1988/Pushok-Flow/actions/runs/44983226714) · [Android candidate](https://github.com/mrkoster1988/Pushok-Flow/actions/runs/44983226709).

Обновление: **Профиль → Версия и обновления → Проверить обновления → Скачать → Установить обновление**. Пакет `shop.pushok.flow` и постоянный сертификат прежние; обновление предназначено для установки поверх опубликованных версий с сохранением данных. Установку подтверждает Android.

Этот выпуск не добавляет автоматическое переподключение или запуск после перезагрузки. Настоящее WireGuard-соединение, DNS, IPv4/IPv6, прямой трафик исключённых приложений и сохранность данных после обновления ещё требуют проверки на телефоне. Удалённое приложение в сохранённых исключениях пока может помешать подключению. Ранее наблюдавшееся предупреждение Play Protect остаётся отдельным открытым вопросом; его устранение этим выпуском не заявляется.
