# Pushok Flow 0.29.0

## Что изменилось

- В «Маршрутах» появился поиск по названию приложения и идентификатору пакета, фильтр «Выбранные» и счётчик исключений. Запрос и фильтр сохраняются при переходах между вкладками.
- Все исключения можно снять одной кнопкой с подтверждением. Приложения, отсутствующие в текущем списке Android, остаются видимыми по package ID и могут быть убраны отдельно.
- Большой список строится по мере прокрутки. Длинные названия ограничены двумя строками; полный текст доступен по долгому нажатию, а переключатель остаётся достижимым при крупном шрифте.
- Выбор считается сохранённым после ответа Android. Конфликт с более новым списком не перезаписывает его; ошибка чтения сохраняет последние данные и предлагает повторить проверку.
- Изменение исключений запрещено при активном или неизвестном состоянии туннеля. Пока идёт сохранение, подключение и изменение профилей также заблокированы. Устаревшее подтверждение очистки после переключения приложения не удаляет список.

Главная остаётся упрощённой: подключение, статус и диагностика. Профили — в «Серверах», исключения — в «Маршрутах».

## Установка обновления

В опубликованной версии откройте **Профиль → Версия и обновления → Проверить обновления**, затем скачайте и подтвердите установку Android. Пакет `shop.pushok.flow` и постоянный сертификат прежние; удалять приложение перед обновлением не требуется.

На телефоне предстоит подтвердить сохранение настроек после обновления и реальный прямой трафик выбранных приложений. Отсутствие приложения в launcher-списке не доказывает его удаление; выпуск не заявляет автоматическое игнорирование удалённых пакетов. Ранее показанное предупреждение Play Protect остаётся отдельным неразрешённым вопросом: эта версия не заявляет его исправление.
