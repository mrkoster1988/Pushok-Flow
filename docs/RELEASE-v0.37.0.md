# Pushok Flow 0.37.0 — фоновые обновления и VLESS WebSocket/gRPC

Подготовлено и подписано: 22.11.2026 (Москва). Версия приложения **0.37.0+37**, пакет `shop.pushok.flow`. Проверки CI, Android-сборка и проверка постоянной подписи завершились успешно. **Публичная публикация ожидает разрешения; workflow выпуска не запущен.** В публичном канале пока остаётся v0.36.0.

## Что меняется

Выпуск объединяет новые транспорты VLESS и автоматический обновлятор в одном APK. По запросу пользователя добавлены периодические фоновые проверки: приложение само проверяет новые выпуски и скачивает APK. Автообновление включено по умолчанию; настройка находится в **Профиль → Версия и обновления**. Android может отложить фоновую работу из-за сети, заряда или системных ограничений.

На Android 12 и новее обновлятор запрашивает самостоятельную установку через штатный `PackageInstaller`. Для этого Android должен разрешать установки из Pushok Flow. Если системе нужно подтверждение, файл сохраняется и ждёт пользователя. Автоматическая установка также ждёт, пока интерфейс и активное соединение не используются. Обычное обновление выполняется поверх прежней версии с тем же сертификатом; удаление приложения не запускается. [Полный порядок](UPDATES.md#автоматические-обновления-в-v0370).

К VLESS TCP/Raw добавляются **WebSocket и gRPC поверх TLS**. Для них используются те же кнопки импорта: вставка ссылки, QR камеры, QR из изображения и текстовый файл. Выбранный транспорт и его параметры передаются в уже встроенный Xray; повторное скачивание движка на телефоне не требуется.

- WebSocket: путь запроса и Host из ссылки.
- gRPC: имя сервиса, authority и обычный либо multi-режим.
- RAW/TCP: прежние TLS и REALITY, с необязательным Vision.

WebSocket и gRPC в этом выпуске требуют TLS и не принимают Vision. Проверка сертификата остаётся обязательной. Несовместимые сочетания и неизвестные параметры отклоняются при импорте. Подсказки находятся в существующем редакторе под ⓘ.

Выпуск не добавляет VMess, Trojan, Shadowsocks, XHTTP, подписки HTTP(S), произвольный JSON и автоматическое подключение после импорта. [Поддерживаемые варианты и инструкция](3X-UI.md).

## Обновление и проверка на телефоне

Для нового импортера, генератора конфигураций и фонового обновлятора нужен один APK с прежним постоянным сертификатом. После публикации при переходе с версии до 0.37 обычный путь: **Профиль → Версия и обновления → Проверить обновления → Скачать → Установить обновление**. Уже установленная старая версия не может получить новый механизм без этого обновления. После установки 0.37 последующие выпуски проверяются и скачиваются автоматически. Откройте приложение для проверки настройки и при необходимости заранее разрешите установку из Pushok Flow в разделе обновлений; при обновлении планирование также запускается системным событием замены APK. Удаление опубликованной подписанной версии не является шагом обновления. Поддерживаемые профили добавляются внутри приложения без новой сборки.

Схема зашифрованного каталога и сохранённые исключения приложений не меняются. Реальное подключение к конкретному серверу, DNS, IPv4/IPv6, исключения приложений, переключение сети и сохранность данных при обновлении требуют отдельной приёмки на физическом Android. Ранее зафиксированное предупреждение Play Protect остаётся отдельной задачей.
