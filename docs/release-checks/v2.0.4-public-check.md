# Pushok Flow 2.0.4 для Android

Сборка 69 опубликована 25 ноября 2026 года. Для коммита `73599f1213239f8cf180167b31185c7e5d93d963` прошли [проверка исходников](https://github.com/mrkoster1988/Pushok-Flow/actions/runs/45696505539) и [сборка Android](https://github.com/mrkoster1988/Pushok-Flow/actions/runs/45696505531).

Манифесты по ссылкам последнего выпуска и тега v2.0.4 указали на один APK. Полное скачивание без авторизации дало 28 694 052 байта и SHA-256 `24827778e2a2fc0ab0e11d25648ea0b2af9abb518563443e1bfd0f5f5e2239a8`. Подпись совпала с постоянным сертификатом 2.0.3.
