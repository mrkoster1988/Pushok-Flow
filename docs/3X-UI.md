# Подключение из 3x-ui

Первый этап поддержки подготовлен для Pushok Flow **0.36.0+36**. 3x-ui — панель управления: совместимость определяется протоколом и параметрами конкретного клиента, а не названием панели.

## Поддерживаемый профиль

В этом выпуске добавляется одна клиентская ссылка **VLESS**, транспорт **TCP / Raw**, защита **TLS** с проверкой сертификата либо **REALITY**. Поддерживается `xtls-rprx-vision`. Существующие профили WireGuard `.conf` продолжают работать.

VMess, Trojan, Shadowsocks, WebSocket, gRPC, XHTTP, подписки HTTP(S), произвольные JSON-конфигурации и новые варианты шифрования VLESS в этот этап не входят. Неподдерживаемые параметры отклоняются с понятным сообщением; они не удаляются из ссылки ради видимости успешного импорта.

Для REALITY нужны соответствующие серверу SNI, публичный ключ, short ID при его наличии и поддерживаемый отпечаток клиента. Приватный ключ сервера в клиент не вводится. На первом этапе принимаются отпечатки `chrome`, `firefox`, `safari`. Отключение проверки сертификата TLS не поддерживается.

Основания: [формат ссылок 3x-ui](https://github.com/MHSanaei/3x-ui/blob/main/docs/content/docs/en/config/share-links.mdx), [спецификация ссылок Xray](https://github.com/XTLS/Xray-core/discussions/716), [REALITY](https://xtls.github.io/en/config/transports/reality.html).

## Как добавить

1. В 3x-ui откройте нужного клиента и скопируйте его ссылку, начинающуюся с `vless://`, либо откройте QR этого клиента.
2. В Pushok Flow откройте **Серверы → Добавить профиль** и задайте название.
3. Выберите **Вставить**, **Сканировать QR**, **QR из фото** или **Из файла** для текстового файла с одной ссылкой.
4. После успешного чтения нажмите **Сохранить**. Профиль хранится в прежнем зашифрованном каталоге.
5. Выберите профиль в «Серверах», затем нажмите кнопку подключения на главной. Если Android запросит разрешение на туннель, подтвердите его.

При добавлении второго профиля текущий выбор сохраняется. Импорт сам не подключает и не меняет маршруты. Отмена или ошибка не заменяют уже введённый черновик. Если QR находится на том же телефоне, используйте **QR из фото**.

## Прямые маршруты и диагностика

Сохранённый список приложений из «Маршрутов» используется и для VLESS. Android исключает выбранные приложения из туннеля при его создании. Для изменения списка сначала отключите текущее подключение. Недоступные Android пакеты не удаляются из выбора молча.

Статус **«Туннель включён»** подтверждает запуск локального туннеля. Он не доказывает успешную авторизацию у сервера или доступность Интернета. Для VLESS не показывается рукопожатие WireGuard; пока числовая статистика Xray не подключена, недоступные показатели отображаются как «—».

## Обновление

Новый протокол содержит нативный сетевой движок, поэтому требует обычного обновления APK с прежним постоянным сертификатом. Удаление установленного подписанного Pushok Flow не является шагом обновления. После установки поддерживаемые профили можно добавлять внутри приложения без новой сборки. Подписанные рекомендации приложений продолжают обновляться отдельно без APK.

Физическая проверка конкретного профиля 3x-ui, переключения Wi-Fi/мобильной сети, DNS, IPv6 и прямого трафика выбранных приложений остаётся отдельным этапом. Для автоматических проверок используются только искусственные профили; реальные клиентские ссылки в репозитории и журналах не сохраняются.
