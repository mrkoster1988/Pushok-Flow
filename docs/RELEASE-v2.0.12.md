# Pushok Flow 2.0.12 — кандидат сетевого исправления

Android, сборка 77. Один универсальный APK, пакет `shop.pushok.flow`.
Статус: подготовка кандидата; этот документ не подтверждает публикацию APK.

## Изменения для пользователя

- Проверка интернета учитывает доступные маршруты IPv4 и IPv6. Неподходящий
  адрес из смешанного DNS-ответа не мешает проверить рабочий путь через туннель.
- Проверка использует конкретный адрес в текущей сети VPN с обычной проверкой
  HTTPS-сертификата и имени сервера. Редиректы не считаются успехом.
- Ожидание ограничено. Stop и смена подключения отменяют результат, даже
  если операция уже завершилась к моменту возвращения диагностического ответа.

## Инструмент для обслуживания серверов

`tools/network_baseline.py` пассивно снимает агрегированные счётчики CPU,
интерфейсов и UDP. По ним можно искать перегрузку CPU/канала, локальные сбросы и ошибки до
изменения настроек. В APK этот административный инструмент не встраивается.
Он не делает вывод о предельной скорости интернета по текущей загрузке.

Согласованное исправление Shop убирает ложный отказ выдачи, когда IPv6
WGDashboard и настроенный IPv6 узла отличаются только формой записи.
Контракт действующих подписок сохраняется.

## Границы кандидата

Автоматический выбор внешнего IPv4/IPv6 endpoint, адаптивный PMTU и включение
IPv6 на VPS требуют следующих этапов [сетевого плана](NETWORK-RELEASE-PLAN.md).
Измеренный прирост скорости, бесшовное переключение и полноценный IPv6-выход
на текущем сервере в этом кандидате не заявляются.

## Проверки перед выпуском

Требуются полный CI точного коммита, универсальная Android-сборка и прежний
постоянный сертификат:
`8b4114881116a920c3351b503052ac27078fdbbfcae1ace27f1af8245ebb7047`.
APK с временной подписью CI не является файлом обновления для пользователей.
Порядок `publish-public-release.yml`, проверка SHA-256 и схемы `update.json`
сохраняются. Реальные результаты подготовки фиксируются отдельно в
`docs/release-checks/`.

Приёмка на телефоне включает IPv4-туннель с A+AAAA DNS, IPv6-туннель,
недоступный адрес, неверный сертификат, Stop/смену сети во время проверки
и сохранение исключений приложений. Проверки исходников не заменяют её.
