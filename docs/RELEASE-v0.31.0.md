# Pushok Flow v0.31.0 — проверка обновлений

Дата: 22.11.2026 (Москва). Версия приложения: `0.31.0+31`.

Статус: изменения готовятся к проверке и публикации; последний опубликованный выпуск — v0.30.0. Статус будет заменён фактическими результатами перед завершением работы.

## Что исправляется

В прошлых выпусках общий адрес `latest/download/update.json` некоторое время возвращал предыдущую версию. Обновлятор трактовал любой номер сборки не выше установленного как последнюю версию и мог удалить запись уже скачанного обновления. Ответ с `Age: 0` также не подтверждал актуальность содержимого.

Теперь ручная проверка получает опубликованный стабильный выпуск из фиксированного GitHub Releases API и строит адрес `releases/download/v<версия>/update.json`. Манифест должен соответствовать выбранному тегу. Проверки пакета, подписи, SHA-256, размера APK и запрет установки версии не новее установленной сохраняются.

Запросы сведений отправляются с отключённым локальным кэшем и заголовками повторной проверки. Один запрос API выполняется при явном нажатии, без фонового сетевого опроса. Автоматическое обновление состояния экрана читает только локальное состояние операции.

## Поведение приложения

- Видны этапы поиска выпуска и проверки сведений о нём.
- Успешная проверка без новой версии сообщает «Новых версий не найдено».
- Показывается дата и время последней успешной проверки. Ошибка или начало новой проверки не обновляют эту отметку.
- Старые/несогласованные сведения, ограничение запросов и ошибка сети имеют понятные отдельные сообщения.
- Подготовленный APK сохраняется при неудачной повторной проверке. Скачивание и установка требуют отдельных нажатий; системное подтверждение Android остаётся обязательным.
- Повторная проверка доступна вместе с кнопкой скачивания или установки.
- Повторное открытие раздела и возврат из фона обновляют состояние незавершённой проверки; запоздавший ответ не должен перезаписать более новое состояние.

Главная, панель ⓘ, анимация Пушка, профили WireGuard и маршруты сохраняют поведение v0.30.0. Новые разрешения Android и зависимости для этой доработки не требуются.

## Что подтверждается отдельно

Заголовки кэширования и выбор конкретного тега не доказывают одновременное обновление всех узлов GitHub. Приложение может обнаружить противоречие с установленной или ранее известной версией, но не может знать о выпуске, которого ещё не видел ни один использованный источник. Поэтому текст результата не обещает абсолютную актуальность.

Ранее найденная версия учитывается в текущем экземпляре Android Activity; сохранённый и повторно проверенный APK учитывается после пересоздания Activity или процесса. Сведения о версии, которая только обнаружена и ещё не скачана, отдельно на диск не записываются. Время проверки также хранится только в памяти; восстановление файла не выдаётся за новую сетевую проверку.

Публикация дополнительно проверяет без авторизации оба пути: общий адрес для установленных старых версий и новую последовательность API → манифест конкретного выпуска. Сохраняются наблюдения HTTP, версия и контрольные суммы; параметры подписанных CDN-ссылок в журнал не попадают. При ответе API 403/429 немедленные повторы прекращаются.

## Проверки

Результаты точного коммита, Android-сборки, подписи и публичного канала будут внесены после завершения проверки. Локальный Python-набор: 141 тест прошёл на промежуточном состоянии; это не заменяет проверку итогового коммита.

## Приёмка на телефоне

1. Обновить прежний опубликованный APK без удаления приложения; проверить профили и исключения.
2. Открыть «Профиль → Версия и обновления», выполнить проверку и увидеть время успешного результата.
3. Уйти на другую вкладку и вернуться во время проверки; повторить со сворачиванием приложения.
4. После загрузки APK отключить сеть и повторить проверку: файл должен остаться готовым, рядом должна появиться ошибка проверки.
5. Проверить интерфейс с крупным шрифтом, разрешение установки, отказ и повторный запуск системной установки.

Настоящий WireGuard-туннель, DNS, IPv4/IPv6 и прямой трафик выбранных приложений по-прежнему требуют испытания на устройстве. Ранее наблюдавшееся предупреждение Play Protect и незавершённое обращение в Google остаются отдельной открытой задачей; этот выпуск не объявляется её решением.
