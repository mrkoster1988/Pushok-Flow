# Pushok Flow v0.55.0 — отчёт об ошибке подписки

## Изменения

Кнопка **«Скопировать ошибку»** доступна рядом с ошибкой добавления подписки,
в карточке подписки после неудачного обновления и у общей ошибки списка.
Она копирует короткий текст с версией Flow, действием, источником импорта,
проверенным кодом и понятной причиной. Отправку пользователь выполняет сам.

Источник сохраняется при прямом добавлении и переходе из редактора профиля:
ручной ввод, буфер обмена, камера, фото, внешняя ссылка или файл.
После изменения полей, новой попытки импорта или успешного обновления старый
отчёт больше не предлагается. Подтверждение копирования относится только
к текущей ошибке в активном окне; поздний ответ не показывает успех для новой
ошибки. При отказе буфера обмена можно повторить копирование.

Текст строится из закрытого списка кодов и фиксированных описаний. Личная
ссылка, её домен, название и ID подписки, имена серверов, конфигурации,
ключи и исходные сообщения платформы не входят в отчёт. Неизвестный код
заменяется на `SUBSCRIPTION_UNAVAILABLE`. Время исходной ошибки, HTTP-статус
и состояние оплаты не добавляются без подтверждённых данных.

Ручное и автоматическое обновление указываются, когда их происхождение
наблюдалось в текущем сеансе. Для восстановленного сообщения используется
общее «Обновление серверов». Отказ ручной попытки до загрузки не меняет
описание старой ошибки провайдера. Завершение более старого обновления
не стирает более новую ошибку сохранения настройки автообновления.

Версия для раздела информации, нового отчёта и встроенной истории берётся
из одного набора констант, сверяемых с `pubspec.yaml`. История пяти выпусков
и описание v0.55.0 доступны в **Профиль → Версия и обновления** без сети.

## Проверки и публикация

Публикация v0.55.0 ожидает обязательных проверок и постоянной подписи APK.

## Границы проверки

Тесты используют синтетические ссылки, управляемые platform channels и
буфер обмена. Они проверяют отсутствие секретных полей, источники импорта,
повторные попытки, ошибки копирования, смену окна и запоздавшие ответы.
Результаты сборки и публикации фиксируются отдельно после завершения.

На физическом Android ещё требуется проверить обновление с сохранением
данных, личный QR, загрузку реальной подписки, копирование ошибки, выбор
сервера и подключение. Полный вход через Telegram и существующий кабинет
MTProxy, фоновая загрузка APK и смена сети сохраняют прежние границы приёмки.
