# Pushok Flow v0.62.0 — права аккаунта, управление конфигом

**Статус:** исходники следующего выпуска, пока НЕ опубликованный APK.

## Новый основной сценарий

- MTProxy подтверждает Telegram-аккаунт через одноразовый подписанный билет.
  Android передаёт в Shop **только билет**, не генерирует и не передаёт
  `client_id`, телефон не используется для авторизации.
- Права на серверную подписку, срок и оплату проверяет Shop по связанному
  `user_id`; клиент не может выбрать произвольную учётную запись.
- На главной под «Получить конфиг» две отдельные команды:
  **«Продлить»** открывает `https://pushok.shop/shop/` в браузере.
  **«Удалить конфиг»** после подтверждения удаляет только локальную личную
  подписку и отключает автоматическое восстановление. Серверный peer,
  остальные ключи, покупки, аккаунт и ручные профили остаются неизменными.
- Те же команды доступны через настройки аккаунта.

## Безопасность и совместимость

- Устанавливается поверх v0.61 тем же постоянным сертификатом
  `8b4114881116a920c3351b503052ac27078fdbbfcae1ace27f1af8245ebb7047`.
- Предыдущие профили и приватные ключи не требуют переустановки.
- Автоимпорт после явного удаления отключён; повторное получение возможно
  по кнопке пользователя.
- Новый Shop должен игнорировать старое поле `client_id` от ранее
  установленных клиентов. Принцип account-only вводится на сервере;
  один Android APK без нового Shop не исправит старую 409 блокировку.
- Несколько одновременных WG соединений с одним private key могут менять
  endpoint. Для стабильной параллельной работы потребуются независимые
  WG peers при едином праве аккаунта.

## Предвыпускные проверки

1. Source contract checks, Flutter 500+ tests, Kotlin, статический анализ.
2. Debug и универсальный Android candidate на точном source SHA.
3. Подпись локально сохранённым ключом, контроль APK v2/v3, zipalign, minSdk,
   package id, SHA-256 и непрерывность версии.
4. GitHub Release: единственный универсальный APK и `update.json`,
   публичный анонимный контроль загрузок.
5. Физический Android после обновления v0.61: отсутствие блокировки
   телефона, запрос личного конфига, продление, удаление без повторного
   импорта, сохранение остальных настроек, реальный peer/handshake/трафик.

**Важно:** публикация APK и исходников не обновляет пользовательский Shop
на VPS. Серверный WGDashboard API должен использовать защищённую связь.
