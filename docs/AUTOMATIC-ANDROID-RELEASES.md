# Автоматические Android-выпуски Pushok Flow

После изменения версии в `pubspec.yaml` и объединения кода с `main`
GitHub Actions автоматически запускает `Android release with in-app updates`.

Для каждой версии выполняются Python/Kotlin/Dart/Flutter проверки, сборка
универсального APK, проверка постоянного Android-сертификата, идентичности
пакета и versionCode, непрерывности публичного `update.json`, затем загрузка
APK, контрольной суммы и манифеста в GitHub Releases. Ошибка любого этапа
останавливает публикацию; debug/candidate APK никогда не является релизом.

Для выпуска следующей версии требуется изменить одновременно:
- `pubspec.yaml` — `version: X.Y.Z+BUILD`;
- `lib/models/app_version.dart` — имя и код той же версии;
- `lib/models/app_release_history.dart` — офлайн-журнал изменений.

Для ранее выпущенной версии номер не переиспользуется. Программа сама
проверяет публикацию и запрещает перезапись существующего тега.

## Обязательное условие постоянной подписи

GitHub Actions должен иметь **оригинальные**, безопасно хранимые secrets
`PUSHOK_ANDROID_KEYSTORE_BASE64`, `PUSHOK_ANDROID_KEYSTORE_PASSWORD`,
`PUSHOK_ANDROID_KEY_ALIAS`, `PUSHOK_ANDROID_KEY_PASSWORD`. Создание нового
keystore не допускается: сертификат должен совпасть с установленной
v0.63.0. По состоянию на 25.11.2026 у выпуска v0.64.0 был отказ
на шаге `Configure persistent private release signing`; см.
[issue #25](https://github.com/mrkoster1988/Pushok-Flow/issues/25).

В ChatGPT, репозиторий и логи нельзя вставлять приватные значения ключа.
После настройки GitHub Secrets пользователь может заново запустить
`Android release with in-app updates` для уже подготовленной v0.64.0.
Будущие версии запускаются автоматически при commit изменения версии.

## Что произойдёт на телефоне

Flow может обнаружить и загрузить подписанное APK в фоне, но обычное
Android-приложение вне системной роли владельца устройства **не может**
бесшумно заменить установленный пакет. Системное подтверждение установки
сохраняется. Данные приложения и профили сохраняются только если сертификат
подписи и имя пакета не изменились.

Автоматический выпуск приложения не создаёт WireGuard peer и не обходит
сроки подписки Shop. Сервер проверяет права аккаунта и личную HTTPS-ссылку.
