# Pushok Flow v0.64.0 — один главный сценарий подключения

Дата подготовки: 25.11.2026. **Исходники кандидата, не свидетельство публикации APK.**

## Главная

- Большая кнопка **«Подключить»** начинает проверяемый вход в существующий аккаунт MTProxy при отсутствии личного профиля, ждёт подтверждения в Telegram и запрашивает персональную подписку Shop. После подтверждённого активного WireGuard-профиля запускает обычный Android VPN flow; разрешение ОС остаётся обязательным.
- Отдельный блок авторизации удалён. Статус и код показываются только пока подтверждается вход. Ручная кнопка получения конфига показывается только при входе без готового профиля.
- **«Продлить через Shop»** находится ниже сведений о соединении; кнопка **«Добавить сервер»** удалена с главной. Ручные профили и удаление локального конфига находятся в настройках.
- Существующие сохранённые ручные подключения продолжают включаться главной кнопкой без принудительной авторизации в MTProxy.

## Повторный вход и защита

- Для **того же проверенного аккаунта** ранее сохранённая защищённая личная HTTPS-ссылка сначала перечитывается напрямую из Shop: без лишнего одноразового MTProxy-билета. Сервер проверяет срок, отзыв и действительность подписки. Чужой аккаунт не получает конфиг.
- При HTTP 429 повторные обмены ограничены таймером; циклы повторного логина не запускаются.
- Выход из аккаунта не стирает платные права Shop. Явное локальное удаление конфигурации отменяет автоматический повторный импорт.

## Подтверждение в Telegram

MTProxy-связка реализуется отдельно: в Telegram Mini App после серверного `approved` вызывается `Telegram.WebApp.close()`. Telegram как приложение не закрывается принудительно; для внешнего браузера нужен ручной возврат в Flow.

## Ограничения и приёмка

Вход сам по себе не создаёт право доступа. Для первого бесплатного WireGuard-подключения владелец должен включить и проверить ограниченную серверную автовыдачу Shop; существующая оплаченная подписка должна быть привязана **к тому же Telegram/Shop user_id**, который подтвердил вход. Никакого переноса по username или автоматического создания дубликатов.

Перед публичным выпуском: Flutter analyzer/tests, Kotlin/native/Android candidate, постоянная подпись, `update.json`, SHA-256 и verified public release. На живом телефоне проверить вход/выход/повторный вход, один peer, актуальный WGDashboard, handshake, трафик и срок действия. GitHub CI не доказывает реальный VPN-трафик.
