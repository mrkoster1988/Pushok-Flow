# Pushok Flow v0.17.0 — безопасная маршрутизация Android

- Изолирована проверка `IncludedApplications` и `ExcludedApplications` в секции `[Interface]`.
- Параметры маршрутизации в `[Peer]` теперь отклоняются до установки туннеля.
- Повторяющиеся `ExcludedApplications` нормализуются в единственное правило по выбору пользователя.
- Добавлены исполняемые Kotlin-тесты регрессии, включая комментарии и неправильные секции.
- Дальнейшие этапы P0: запуск Android CI на GitHub, реальная сборка APK и тест устройства.

Ограничение: Flutter/Android SDK в текущем окружении отсутствуют. Работа VPN и APK не подтверждены.
