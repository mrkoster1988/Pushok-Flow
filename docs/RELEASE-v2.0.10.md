# Pushok Flow 2.0.10

## Изменения

- Режим «Сайты напрямую» включается отдельным переключателем. После обновления он выключен; сохранённый список сайтов остаётся доступен для повторного включения. После изменения режима переподключите Flow.
- На главном экране показывается «Ожидание отклика», если свежая статистика WireGuard подтверждает, что успешный обмен с сервером ещё не зафиксирован. Недоступная или устаревшая статистика не выдаётся за отсутствие ответа.
- Настройки прямого подключения отдельных приложений сохраняются.

Эти изменения не подтверждают исправление текущего соединения с сервером: для этого нужна проверка реального обмена и трафика после обновления.
