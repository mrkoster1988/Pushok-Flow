# Архитектура v0.1

## Границы модулей

- Flutter: экраны, состояния UI, настройки, прозрачная индикация прямого трафика.
- Android Kotlin: VpnService, WireGuard engine, проверка пакетов, применение исключений перед establish().
- iOS Swift: NEPacketTunnelProvider, маршруты, политика Network Extension; без недоступных iOS per-app обещаний.
- Pushok ИИ: локальные детерминированные рекомендации + опциональный серверный агент. Личная память и согласие на телеметрию.
- API: Pushok ID (идентификация), Engine (конфигурации), Proxy (Telegram-only MTProxy).
- Updates: клиенты обновляются из магазинов, правила — по подписанному манифесту.

## Android bypass

Список package name должен быть подтверждён установленными приложениями на устройстве. Для режима VPN-all применяется `addDisallowedApplication(packageName)` **перед** `establish()`; обновление списка требует пересоздания VPN. Android «Always-on VPN / Block connections without VPN» может влиять на возможности обхода — отдельно предупреждаем пользователя и тестируем.

## Приёмочные критерии первого инженерного релиза

1. Реально работающий WireGuard-туннель; таймауты, reconnect, kill switch — по выбранной политике.
2. Отдельный прямой маршрут Android для MAX, VK, банков, маркетплейсов по согласованному списку.
3. Два проверяемых внешних IP (туннель и прямой) в контролируемых тестах; DNS и IPv6 проверены отдельно.
4. Персональные правила не сбрасываются после обновления.
5. Обновления подписаны и проверены до применения, недоверенные отклоняются; история и безопасный откат правил.
6. Pushok ИИ не меняет защищённые правила без согласия и объясняет причины.
