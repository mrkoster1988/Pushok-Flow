# Pushok Flow 0.34.0 — рекомендации без установки APK

Дата: 22.11.2026 (Москва). Версия приложения: `0.34.0+34`.

Статус: исходники подготовлены, проверки и публикация ещё не завершены. Установленная v0.33.0 пока не содержит нового канала данных.

## Что меняется

В «Маршрутах» появляется карточка рекомендаций с собственной версией данных, временем успешной проверки и кнопкой «Обновить рекомендации». Подписанный список поступает внутри приложения без запуска установщика Android. Фильтр «Рекомендованные» показывает только локально видимые приложения, чьи точные идентификаторы есть в списке. Названия берутся с телефона.

Первоначальная версия данных содержит четыре проверенных пакета: MAX, ВКонтакте, Ozon и Wildberries. Это предложения для ручного выбора, а не автоматическое назначение прямого маршрута. Обновление данных не меняет пользовательские исключения и профили, не отключает и не переподключает WireGuard. Полный список приложений и прежние переключатели работают независимо от сетевой проверки рекомендаций.

Для внедрения этого клиента нужен один обычный APK поверх предыдущего приложения. Далее список обновляется отдельно, без нового APK. Логика Flutter, Kotlin, разрешения и библиотеки по-прежнему обновляются полноценным выпуском. [Подробные границы и порядок доставки данных](NO-APK-UPDATES.md).

## Защита и сохранение данных

Пакет приложения и постоянный Android-сертификат сохраняются. Данные рекомендаций подписываются тем же сохранённым ключом с отдельной доменной строкой; клиент проверяет подпись открытым ключом установленного APK. Закрытый ключ не публикуется и не передаётся GitHub Actions.

Клиент проверяет строгую схему, ограниченный размер, уникальность пакетов и номер данных. Старый ответ или противоречивая версия не заменяет принятый список. Приватный кэш записывается атомарно и повторно проверяется при чтении. Ошибка подписи, сети или записи сохраняет последний подтверждённый каталог. В канале нет кода, адресов серверов и параметров туннеля.

## Проверки

Результаты точного исходного коммита, подписи APK и публичного канала будут внесены после выполнения. Новые тесты проверяют подпись и подмену данных, версии и транзакции хранения, отсутствие автоматического выбора приложений, пересечение с локальным списком и запоздалые ответы при смене состояния приложения.

## Границы приёмки

На физическом Android остаются проверка обновления поверх предыдущей версии с сохранением профилей и исключений, получение рекомендаций из публичного канала и реальный трафик выбранных приложений. Подпись и тесты не заменяют эту проверку. Предупреждение Play Protect остаётся отдельной нерешённой задачей.
