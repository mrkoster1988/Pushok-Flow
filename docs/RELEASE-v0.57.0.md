# Pushok Flow v0.57.0 — управляемые WireGuard-подписки

## Что изменилось

Добавлен клиентский формат `pushok-flow-subscription` версии 1 для
персональных HTTPS-подписок устройств. Он предназначен для выдачи через
существующий Shop с отдельным сервером WGDashboard.

- Полные WireGuard-конфигурации проверяются настоящим parser библиотеки до
  изменения каталога. Повреждённый JSON, ключи, адреса, Endpoint, дубликаты и
  несовместимые параметры не заменяют рабочие настройки.
- Стабильный идентификатор профиля сохраняет выбор сервера при обновлении
  имени, адреса или ключей. Изменённый ответ требует новой ревизии; старая
  ревизия и переход на другой формат при обновлении отклоняются.
- Подтверждённые состояния `expired` и `revoked` удаляют только принадлежащие
  подписке профили. Карточка остаётся для обновления после восстановления
  доступа. Импорт и обновление не включают соединение автоматически.
- Срок проверяется перед загрузкой, выбором и запуском управляемого профиля,
  включая повторную проверку после системного разрешения Android.
  Уже работающий туннель эта версия по таймеру подписки не отключает.
- Состояние и время видны в карточке; сообщения добавления, обновления и
  подключения учитывают истечение и отзыв. Секреты и provider ID не входят
  в общие метаданные и диагностические отчёты.
- Шифрованный каталог записывается в схеме 3 с прежним ключом; схемы 1/2
  читаются без повторного импорта. Обычные VLESS-подписки, ручные профили и
  исключения приложений сохраняют прежнее поведение.

## Границы этого этапа

Shop ещё должен выдавать согласованный JSON для WireGuard. Доступность
панели, выдача реальной подписки, трафик, продление и отзыв на физическом
телефоне требуют отдельной приёмки. Снятие ссылки скачивания не запрещает
использование уже полученного `.conf`: ограничение peer выполняет сервер.

Pushok ID и новый auth-домен не входят в этот выпуск. Текущая сессия Flow
сохраняет чтение профиля/баланса MTProxy и не используется как разрешение
Shop или административный ключ WGDashboard.
