# Pushok Flow 2.0.11

Android, сборка 76. Один универсальный APK, пакет `shop.pushok.flow`.

## Изменения

- Перед подключением Flow обновляет управляемую подписку. При временной сетевой ошибке можно использовать сохранённый профиль, только пока доступ действует.
- Переход на заранее сохранённый резерв разрешён только при подтверждённой системной защите трафика. Если условия не выполнены, Flow сохраняет текущее подключение и предлагает ручной переход через раздел серверов.
- Кнопка «Отключить» отменяет ожидающее подключение, в том числе из виджета или после системного запроса разрешения Android.
- Настройки маршрутов сохраняются. Переключение проверяет текущий аккаунт и срок подписки; при действующей сессии повторный вход через Telegram не нужен.

## Условия перехода на резерв

Автоматическая смена узла относится только к управляемым WireGuard-профилям
одной подписки. Резерв должен быть подготовлен сервером и сохранён в Flow
до потери основного узла. Каталог обновляется только при выключенном туннеле.
Недоступность API во время аварии не создаёт новый профиль и не продлевает
срок доступа.

Переход требует двух последовательных неудачных проверок DNS/HTTPS через VPN
и действующей подписки. Для профиля, привязанного к аккаунту, сохраняется
проверка разрешения этого аккаунта. Состояние UP, handshake
и рост счётчиков сами по себе не считаются подтверждением доступа в Интернет.
Повторные попытки ограничены; бесконечного переключения между узлами нет.

Автоматический переход разрешён только на Android 10+ при уже включённой
системной блокировке соединений вне VPN и подтверждённом владельце работающего
VPN service. Неизвестный или базовый service WireGuard, в том числе при части
запусков Always-on, не разрешает автоматическую остановку туннеля для смены
узла. Подробные условия описаны в
[документе об управляемых узлах](MANAGED-NODE-RECOVERY.md).

Flow не включает системную блокировку самостоятельно. Она может мешать
прямому подключению приложений, исключённых пользователем из VPN. Сохранение
списка исключений не отменяет этих ограничений Android. Переход может оборвать
текущие соединения и изменить внешний IP; бесшовное восстановление не заявлено.

## Состояние проверки и выпуска

Изменения подготовлены совместно с управлением узлами в Shop 2.028 и Mini App
2.51. Это указание на совместимую разработку, а не подтверждение развёртывания
серверов или готовности конкретного резервного узла.

Для версии 2.0.11 требуется успешный CI точного коммита и подпись тем же
постоянным сертификатом, что у 2.0.10:
`8b4114881116a920c3351b503052ac27078fdbbfcae1ace27f1af8245ebb7047`.
Схема `update.json` и штатный порядок публикации сохраняются. Подготовка
этого описания не подтверждает появление APK в публичном канале.

Приёмка на физическом Android ещё не выполнена. Требуется проверить установку
поверх текущей версии с сохранением аккаунта и маршрутов, реальный отказ
основного узла и трафик через резерв, оба режима системной блокировки,
прямые исключения приложений, остановку во время перехода, истечение доступа
и выход из аккаунта. Успешная сборка и публикация не заменяют эти проверки.
