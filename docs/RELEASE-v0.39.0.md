# Pushok Flow 0.39.0 — компактный APK

Подготовка: 22.11.2026 (Москва). Версия **0.39.0+39**, пакет `shop.pushok.flow`. Результаты полной сборки, постоянной подписи и публичной загрузки добавляются после выполнения.

## Почему прежний APK занимал 168 МБ

Подписанный APK v0.38.0 имеет размер **167 714 866 байт**. Из них **164 998 848 байт** — нативные библиотеки для трёх архитектур: `arm64-v8a`, `armeabi-v7a` и `x86_64`. Они хранились в ZIP без сжатия. В сумме Xray занимает **104 609 300 байт**, Flutter — **32 271 844 байта**, код приложения — **17 664 504 байта**, библиотеки WireGuard — **10 453 200 байт**. Ресурсы, включая изображения маскота, занимают около 1,9 МБ внутри APK.

Это измерение содержимого самого APK, а не размера установленного приложения или расхода оперативной памяти. [Подробный разбор v0.38.0](development-checks/apk-size-v038.json).

## Изменение упаковки

Android Gradle Plugin получает `packaging.jniLibs.useLegacyPackaging = true`. Библиотеки остаются внутри подписанного APK в штатном ZIP DEFLATE; при установке Android извлекает библиотеки для выбранной архитектуры. Приложение не загружает исполняемые движки отдельно. Официальные закреплённые версии Xray и WireGuard, три архитектуры и функции приложения сохраняются.

Bootstrap поддерживает один собственный блок Gradle, сохраняет остальные параметры и корректно обрабатывает повторный запуск. Устаревший `extractNativeLibs` из исходного манифеста удаляется, чтобы окончательный параметр сформировал AGP. Повреждённые границы собственного блока останавливают подготовку.

Новая проверка готового release APK требует все 18 библиотек, DEFLATE, непустые записи, отсутствие дубликатов и явное `extractNativeLibs=true` в объединённом манифесте. Прежние проверки Xray ELF 16 КиБ, лицензий, приватности компонентов и обновлятора сохраняются. Для старых APK действует прежний набор требований; debug-сборка не обязана содержать release AOT-библиотеку `libapp.so`.

## Обновление и границы результата

Схема `update.json`, packageName и постоянный сертификат сохраняются; versionCode увеличен до 39. Обновление предназначено для установки поверх прежней подписанной версии. Профили, настройки, интерфейс, импорт QR и фоновый обновлятор не меняются.

Сжатие уменьшает скачиваемый APK. Android дополнительно распаковывает библиотеки при установке, поэтому размер установленного приложения, время установки, запуск и расход памяти нельзя выводить из размера загрузки. Работа и обновление на физическом телефоне требуют отдельной приёмки.
