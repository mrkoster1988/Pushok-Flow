# Pushok Flow v0.24.0 — обновления из приложения

Версия приложения: `0.24.0+24`.

## Основное изменение

В **Профиль → Версия и обновления** добавлены действия **Проверить обновления**, **Скачать**, **Разрешить установку** и **Установить обновление**. Приложение получает описание выпуска из GitHub Releases, показывает новую версию и загружает APK по нажатию. Установку подтверждает пользователь в системном окне Android.

Для регулярных выпусков закреплён постоянный сертификат с SHA-256:

```text
8b4114881116a920c3351b503052ac27078fdbbfcae1ace27f1af8245ebb7047
```

Следующие версии с тем же сертификатом и большим номером сборки предназначены для обновления поверх установленного приложения с сохранением его данных. Полный порядок пользователя и выпуска описан в [UPDATES.md](UPDATES.md).

## Поведение обновлятора

- Перед предложением обновления проверяются метаданные выпуска, совместимость SDK, номер сборки и совпадение сертификата с установленным приложением.
- После загрузки проверяются размер, SHA-256, пакет, версия и фактическая подпись APK. Перед установкой проверки повторяются.
- Готовый APK сохраняется с публичными метаданными и восстанавливается после пересоздания приложения только после повторной проверки. Это позволяет продолжить после возврата из настроек разрешения.
- Установка требует отдельного нажатия. Если приложение ушло в фон во время проверки перед установкой, готовый файл остаётся доступен, а запуск установщика требует нового действия.
- Повторные операции во время проверки или загрузки блокируются; интерфейс получает безопасные коды ошибок.

Очистка кэша Android может удалить загруженный APK; его можно скачать повторно. Полный сценарий установки на физическом телефоне ещё не подтверждён.

## Включённые исправления редактора

Из промежуточной v0.23.0 включены нижний SafeArea для кнопок сохранения, отдельный учёт клавиатуры и понятная подсказка о формате WireGuard. Нужен полный `.conf` с разделами `[Interface]` и `[Peer]`; отдельный UUID отклоняется до нативного сохранения. Неоновое оформление редактора сохранено.

## Однократный переход со старого debug APK

Постоянный сертификат отличается от временных ключей прежних debug-сборок, поэтому поверх такой установки v0.24.0 установить нельзя. Перед однократным удалением старого приложения сохраните исходный `.conf` вне Pushok Flow и запишите выбранные исключения. Удаление очищает профиль, исключения и локальные оценки Pushok ИИ. После установки подписанного v0.24.0 дальнейшие выпуски должны использовать тот же постоянный ключ.

## Сборка и результаты

Путь этого выпуска: **release-кандидат в CI → локальная подпись постоянным ключом через apksigner → проверка итогового APK → GitHub Release**. Для публикации workflow `publish-verified-update.yml` восстановил те же байты подписанного APK из проверенного кандидата и публичного описания различий, затем сверил окончательные SHA-256 и сертификат. Повторная сборка не выполнялась; закрытый ключ в CI не передавался. Дополнительный workflow с GitHub secrets подготовлен для будущего ручного запуска и пока не активирован.

## Что ещё проверить на телефоне

Запись v0.22.0 подтвердила запуск и работу интерфейса, вкладок, исключений и локальной обратной связи. Она выявила перекрытие кнопки редактора системной панелью. Реальный туннель Flow VPN и маршруты трафика на записи не подтверждены.

Для v0.24.0 остаются испытания нижнего отступа и клавиатуры, полного WireGuard-профиля, настоящего VPN и исключений. Для проверки обновления потребуется следующий опубликованный выпуск с большим `versionCode`: необходимо пройти системную установку и убедиться в сохранности профиля, исключений и оценок Pushok ИИ. До такой проверки нельзя считать обновление на телефоне или работу VPN подтверждёнными.
