# Flow: права аккаунта, удаление локального конфига и продление

Изменение после Android v0.61: привязка WireGuard **не зависит от
`client_id` телефона**. Доказательство личности: только одноразовый
подписанный билет Telegram/MTProxy → Shop, где проверяется связь с Shop
`user_id`. Приватные подписки, ключи, токены и ссылки не попадают во Flutter
или внешние URL. В новом Flow обмен передаёт только ticket, сервер Shop
сохраняет обратную совместимость для старых клиентов.

На главной появляются **«Продлить»** и **«Удалить конфиг»** после
подтверждённого входа. «Продлить» безопасно открывает фиксированный
`https://pushok.shop/shop/`, где можно купить продление или выбрать
свой тариф. Сам Flow не начисляет дни, не списывает деньги и не изменяет
удалённый WG peer.

«Удалить конфиг» после подтверждения удаляет управляемую подписку **только
из приложения**. Одновременно локально отключается автоимпорт: при следующем
запуске Flow не восстановит удалённый конфиг сам. Аккаунт, платное право,
история, ручные профили и другие подписки сохраняются. Получить личный
конфиг можно снова по явному запросу.

Существующее ограничение WireGuard: если скопировать один private key на
несколько одновременно работающих телефонов, peer может менять endpoint
и связь будет нестабильна. Поэтому отдельные независимые WG peer для
одновременных сессий остаются отдельным техническим этапом; ограничение
права аккаунта по телефону убрано.

До признания сценария рабочим в production нужно установить новую версию
Shop на VPS, подтвердить WGDashboard по защищённому API, проверить peer
и испытать Flow на настоящем Android. Не копировать конфиги/QR в чат.
