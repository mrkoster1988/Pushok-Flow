# Pushok Flow 0.40.0 — APK под устройство

Подготовка: 22.11.2026 (Москва). Версия **0.40.0+40**, пакет `shop.pushok.flow`. Размеры, результаты CI, постоянной подписи и публичной проверки фиксируются после выполнения; подготовка исходников сама по себе не означает опубликованный или проверенный на телефоне выпуск.

## Поведение обновления

Flow выбирает самостоятельный APK по порядку `Build.SUPPORTED_ABIS`, который сообщает Android. В выпуск входят ARM64 (`arm64-v8a`), ARM32 (`armeabi-v7a`), x86_64 и универсальный APK. Пользователь не выбирает архитектуру вручную. Библиотеки нужного варианта остаются внутри подписанного APK; отдельная загрузка исполняемых движков не вводится.

Версия, versionCode, packageName, minSDK и сертификат у всех четырёх APK одинаковые. Это полноценные устанавливаемые пакеты, а не части одного разделённого APK, требующие совместной установки.

Сжатие нативных библиотек из v0.39 сохраняется. В универсальном файле остаются все 18 библиотек для трёх архитектур, в отдельном варианте — шесть обязательных библиотек его архитектуры. Xray и WireGuard не урезаются по протоколам.

## Совместимость старых клиентов

Общий `update.json` сохраняет прежнюю schema 1 и ровно девять полей, с адресом универсального APK. Старые версии продолжают проверять, скачивать и устанавливать обычный выпуск. При переходе с v0.39 встроенный обновлятор ещё получает универсальную v0.40; автоматический выбор начинает работать после её установки и применяется к следующим обновлениям.

Новый клиент использует уже полученные метаданные GitHub Release. Версия, номер сборки, минимальный SDK и ожидаемый сертификат берутся из прежнего манифеста. Адрес, размер и SHA-256 выбранного APK берутся из проверенной записи файла выпуска. Дополнительного сетевого запроса за индексом вариантов нет.

Если вариантов нет, используется универсальный APK. Если найден хотя бы один известный вариант, требуется полный набор трёх архитектур и универсальный файл с совпадающими метаданными. Неполный набор, дубликаты нужных имён, некорректный размер, digest, состояние или URL отвергаются.

## Кэш и защита установки

Уже известный или готовый файл того же выпуска сохраняется, если он точно совпадает с одной из актуально опубликованных совместимых альтернатив. Это предотвращает лишнюю загрузку после повторной проверки и перезапуска. Проверка свежести продолжает отвергать откат и изменение байтов того же выпуска.

Скачивание разрешает только выбранный канонический URL и прежние адреса доставки GitHub; переход на APK другой архитектуры не разрешается. Перед установкой сохраняются проверки размера, SHA-256, пакета, versionCode, minSDK и единственного постоянного сертификата. Для ABI-варианта также проверяются ZIP-записи обязательных библиотек, отсутствие других архитектур и дубликатов.

Фоновые проверки, загрузка, ожидание завершения активного соединения и подтверждение установки Android сохраняют существующее поведение. Удаление приложения не используется как способ обновления.

## Сборка и выпуск

Закреплённый Flutter 3.50.0 поддерживает отдельные APK по ABI и флаг `force-version-code-ignoring-abi=true`. Он сохраняет номер сборки 40 у всех файлов вместо стандартных смещений по архитектурам. Gradle дополнительно создаёт универсальный APK. Одна сборка должна дать четыре проверенных кандидата из одного коммита.

Постоянная подпись выполняется для каждого точного кандидата. Новая schema 2 описания публикации хранит универсальный файл и ровно три варианта, с отдельной проверкой неизменности содержимого при подписи и восстановления точных байтов. Старая schema 1 продолжает обслуживать прежние выпуски.

До публикации проверяются все девять файлов выпуска: четыре APK, четыре checksum и прежний `update.json`. Workflow сначала собирает и проверяет полный черновик, затем публикует его как latest. Закрытый ключ в CI не передаётся.

## Границы проверки

Размеры загрузок измеряются по готовым подписанным APK. Размер установленного приложения, RAM, время установки и запуск не выводятся из размера файлов. Обновление на реальном телефоне, сохранение профилей, работа туннеля и условия самостоятельной установки Android требуют отдельной приёмки.
