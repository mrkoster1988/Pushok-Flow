# Автоматическое личное WireGuard-подключение через Pushok (Android v0.59.0)

## Задача
Пользователь авторизуется через прежний аккаунт MTProxy Pushok и может получить
свой WireGuard-профиль из Shop через кнопку «Получить моё подключение» в
«Профиль → Аккаунт Pushok». Без QR, ручного импорта ссылки и отдельной
регистрации. После явного включения «Получать подключения автоматически»
проверка выполняется при возвращении в профиль, не чаще 1 раза в 5 минут в
процессе приложения. Обычный ручной импорт WireGuard/VLESS сохраняется.

## Контракт трёх проектов
1. MTProxy `POST /api/v1/flow/shop-ticket` с действующей сессией Flow и
   `{"consent":true}`. Сервер подписывает билет на 60 секунд, указывая
   только MTProxy UUID и проверенный Telegram ID. Без серверного
   `FLOW_SHOP_BRIDGE_SECRET` endpoint отвечает 503.
2. Shop `POST /shop/api/flow/bridge/exchange` получает этот билет и случайный
   идентификатор телефона `pfc_<43>`. Сервер проверяет HMAC, audience,
   TTL, одноразовый jti, соответствие Telegram ID и собственное право
   пользователя. В ответе может быть личная HTTPS-подписка или безопасный
   статус `pending`, `expired`, `revoked`, `disabled`,
   `unavailable`, `link_disabled`.
3. Flow загружает подтверждённую личную подписку через существующий
   `SubscriptionDownloader` и валидирует документ
   `pushok-flow-subscription` v1/настоящий WireGuard Config.
   Сохранение проходит через общий process operation gate, только при
   известном выключенном туннеле. Никакого автоматического подключения
   или подмены ручных профилей.

## Безопасность Android
- MTProxy access token, билет, полный HTTPS URL и приватные конфигурации
  не попадают в Flutter, журнал и метаданные интерфейса.
- Личный профиль хранится через прежний `SecureWireGuardStore` с Android
  Keystore. Локальная дополнительная запись содержит только UUID владельца,
  SHA-256 нормализованного URL и случайный идентификатор устройства (не
  настоящий адрес или ключ). Резервное копирование приложения отключено.
- Привязка владельца фиксируется до импорта. Если аккаунт изменился,
  импорт другого профиля запрещён до явной отвязки.
- Перед Android VPN-разрешением **и повторно после него** native-клиент
  проверяет соответствие активного аккаунта личному профилю. Выход,
  отзыв сессии и смена аккаунта не дают заново запустить старый ключ.
  Уже работающий туннель Flow не отключает самопроизвольно.
- «Отвязать личное подключение» удаляет только привязанную подписку с
  устройства при выключенном туннеле; удаление на телефоне не отзывает
  WG peer на сервере. Для отзыва требуется отдельная операция Shop.
- Отдельный переключатель автоматической синхронизации по умолчанию
  **выключен**. При обычном входе Flow продолжает читать только профиль и
  баланс; новый обмен выполняется после согласия пользователя.

## Развёртывание, безопасность и приёмка
Этот код сам по себе **не включает** связку на действующем VPS.
На обеих серверных сторонах надо согласованно установить отдельный случайный
секрет `FLOW_SHOP_BRIDGE_SECRET` (ровно 64 нижних hex символа), не совпадающий
с MTProxy SESSION_SIGNING_KEY, BOT_TOKEN, Shop admin key или WGDashboard API key.
Секрет не хранить в репозитории и не отдавать APK.

Shop: настроить личный HTTPS-маршрут `/shop`, подключить и проверить
WGDashboard API. Автовыдача начального бесплатного доступа остаётся выключенной
до решения владельца о сроке/квотах и проверки **серверного** истечения peer.
Существующие оплаченные права доступа не меняются.

Сквозной тест: один существующий аккаунт, один телефон, получение профиля,
трафик, повтор входа без дубля, продление/отзыв, выход и запрет запуска,
смена аккаунта, отвязка, отсутствие доступа при 401/403/409,
потеря ответа/retry, обновление приложения поверх прежнего APK.
Сначала тестовая инфраструктура, затем реальный телефон. Отчёт CI
не подтверждает работоспособность конкретного WGDashboard или боевого Shop.

## Ограничения текущего этапа
- Первая привязка: **один основной профиль на устройство**. Для второго
  телефона нужен отдельный peer и отдельный протокол согласования, не копия
  приватного ключа первого телефона.
- При ротации персонального URL автоматическая миграция консервативно
  останавливается с `SHOP_LINK_CHANGED`; требуется явная отвязка и повтор
  импорта, чтобы не смешать владельцев.
- Android OS не позволяет безусловно установить новый APK без согласия,
  если приложение распространяется в обход магазина приложений.
