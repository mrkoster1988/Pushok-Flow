# Подписка Pushok в Flow

## Единый вход

**[@pushok_app](https://t.me/pushok_app)** — главная точка входа всей экосистемы Pushok. Регистрация, оплата, продление и управление доступом начинаются там. В Flow кнопки аккаунта открывают этот же адрес. Отдельный бот Flow не создаётся.

Flow получает настройки подключения через персональную HTTPS-ссылку подписки магазина. Оплата и состояние аккаунта остаются на стороне сервиса. Открытие Telegram из приложения само по себе не означает вход в общий аккаунт: в этой версии нет обмена токеном авторизации между Telegram и Flow.

## Как добавить серверы

1. Откройте `@pushok_app` и свой кабинет магазина. Для действующей платной подписки VLESS откройте «Ссылка подписки» и включите её, если ссылка ещё не создана.
2. Нажмите «Открыть в Pushok Flow». Страница перехода предлагает открыть приложение; Flow показывает защищённую форму с источником серверов. Подтвердите «Добавить подписку».
3. Альтернатива: скопируйте HTTPS-ссылку и откройте **Серверы → Подписки → Добавить подписку → Вставить**.
4. Выберите сервер и включите подключение на главной. Импорт сам по себе не включает соединение.

Кнопка магазина появляется после обновления его кода. Для работающего Telegram Mini App нужны настроенные HTTPS-адрес магазина, токен и действующая установка сервиса. Публикация исходников не обновляет уже работающий VPS автоматически.

Поддерживается и совместимая ссылка из собственной панели 3x-ui. Нужна именно ссылка подписки HTTPS; отдельный `vless://` по-прежнему добавляется обычным редактором профиля.

## Обновление и срок

Flow сохраняет до пяти подписок в общем лимите двадцати профилей. Серверы из подписки отмечены её названием. Обновление заменяет только серверы этой подписки; ручные профили и другие подписки сохраняются. Существующий выбранный сервер остаётся выбранным, пока его конфигурация присутствует в новом списке.

Автоматическое обновление серверов проверяется при открытии приложения и возвращении в него: не чаще одного раза в шесть часов после успеха и одного раза в час после неудачной попытки. Это отдельная настройка от фоновой загрузки обновлений самого приложения. При закрытом Flow эта версия не запускает отдельного фонового задания обновления подписок.

Для изменения списка серверов собственное подключение Flow должно быть отключено. Сетевой запрос не удерживает блокировку туннеля; перед сохранением приложение повторно проверяет его состояние. Ошибка сети, неверный ответ или конфликт не стирают прежний список.

Срок доступа и счётчики трафика берутся из заголовка `Subscription-Userinfo`. Если сервис их не передал, приложение показывает отсутствие данных. Flow не придумывает срок, не подтверждает оплату и не продлевает подписку локально. Доступ ограничивается сервером провайдера.

Удаление подписки требует подтверждения и удаляет только её серверы с этого устройства. Оно не отменяет оплату или подписку в магазине. Продление и управление оплатой — через `@pushok_app`.

## Формат и ограничения первой версии

- HTTPS, до трёх перенаправлений также на HTTPS; ответ не более 512 КиБ.
- UTF-8 список `vless://` по одному на строку или его Base64-представление. Это совпадает с форматом `/sub/{token}` магазина Pushok.
- Применяются существующие ограничения VLESS: TCP с TLS или REALITY, WebSocket и gRPC с TLS. Неподдерживаемая запись отклоняет ответ целиком.
- URL с логином/паролем, fragment, локальным адресом или приватным IP не принимается. Адреса DNS проверяются перед запросом.
- QR для отдельного WireGuard/VLESS остаётся прежним. Чтение HTTPS-подписки из QR в этот выпуск не входит.

Персональная ссылка даёт доступ к конфигурации: её нельзя публиковать. На устройстве ссылка и серверы находятся в зашифрованном каталоге. В общие метаданные интерфейса передаются название, домен, количество серверов, время и счётчики; секретный URL туда не включается. Поле ввода защищено от снимков экрана и по умолчанию скрыто.

## Переход из магазина

Приложение принимает узкую ссылку `pushokflow://subscription?url=<HTTPS-URL>&name=<название>`. Внешняя ссылка открывает только черновик. Загрузка и сохранение требуют нажатия пользователя в приложении.

Для Telegram Mini App магазин использует промежуточную HTTPS-страницу. URL подписки передаётся в fragment после `#`, не в запросе к веб-серверу. Переход в приложение выполняется явной кнопкой. Пароли панели, токен бота и Telegram ID приложению не нужны.

## Проверка на реальном устройстве

Отдельно требуется подтвердить полный пользовательский путь: `@pushok_app` → работающий магазин → действующая оплаченная подписка → импорт → реальный трафик → продление → обновление срока. Автоматические тесты формата, хранения и переходов не подтверждают приём платежа, доступность конкретной панели или работоспособность туннеля на телефоне.
