## Получение внутри Pushok Flow

Откройте **Маршруты → Обновить рекомендации → Рекомендованные**. Карточка после успешной загрузки покажет версию данных **3**. Фильтр отображает только совпадения с локально доступными приложениями; отсутствие неустановленного банка в списке ожидаемо.

В v0.35.0 можно включить **«Обновлять автоматически»**. Проверка возможна при открытии или возвращении в раздел, с действующими ограничениями частоты. Для немедленной проверки используется ручная кнопка. [Подробное поведение](NO-APK-UPDATES.md).

Прямое подключение каждого приложения выбирается вручную. Получение каталога не включает новые исключения, не меняет профили и не переподключает туннель. Сам список не доказывает, что банк требует прямого маршрута, и не обещает устранение его системной проверки активного подключения.

## Проверка выпуска данных

Публикуются только исходный JSON, подписанный конверт и Markdown-документация. Код приложения, зависимости, разрешения, `pubspec.yaml`, тег и файлы APK v0.35.0 не меняются. Для такого набора путей Android candidate не запускается; Source checks продолжает проверять проект и подпись каталога.

Перед изменением публичный файл №2 прочитан без авторизации и проверен: 966 байт, SHA-256 `86a0615776d6f6435558434797ba5a144dc5e4dab67cde8ce8badcf7a6bec5af`. Его копия использована как предыдущая подписанная версия. Новый номер строго увеличен 2→3; старый конверт не удалялся для обхода проверки.

Подпись использует прежний сертификат SHA-256 `8b4114881116a920c3351b503052ac27078fdbbfcae1ace27f1af8245ebb7047` и отдельную доменную строку данных. Закрытый ключ и пароли не передаются в GitHub. Формат проверяется тем же опубликованным клиентом, который принимает только ограниченный список идентификаторов, без исполняемого кода и параметров туннеля.

Приёмка на телефоне остаётся отдельной: версия данных 3, видимость установленных банков, сохранение выбранных исключений и реальный маршрут после явного подключения. Публичная проверка файла не подменяет эти испытания.

## Первоначальная настройка Flow 0.58.0

Для **новой установки** пакет рекомендаций встроен в APK и не требует ожидания
сети. При первом запросе списка маршрутов сохраняются исключения только для
обнаруженных Android рекомендованных приложений. Автоматическое получение
подписанных новых рекомендаций включено по умолчанию, но срабатывает только при
открытии раздела «Маршруты»/возвращении на него, не в закрытом приложении.

Для **существующей установки** сохранённые исключения и выбор переключателя
«Обновлять автоматически» сохраняются без принудительного включения. Даже
пустой сохранённый список рассматривается как сознательный выбор и не
перезаписывается. Получение нового списка рекомендаций не добавляет приложения
в исключения без отдельного действия пользователя. Применение настроек к
маршрутизации происходит при следующем подключении, а не посреди сеанса.

Автоматическое обновление **APK** является отдельным механизмом (раздел
«Версия и обновления») и уже включено по умолчанию в Android; установка
зависит от системного разрешения Android и подтверждения, когда оно требуется.
Публикация APK v0.58.0 и его проверка выполняются отдельно от CI исходников.
