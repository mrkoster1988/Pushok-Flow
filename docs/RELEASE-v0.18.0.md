# Pushok Flow v0.18.0 — дизайн по эталону

- Введены единые токены цветовой гаммы по скриншоту Pushok Proxy.
- Общие карточки с тонкой границей, кнопки, переключатели, нижняя навигация и статусные чипы.
- Главная: оригинальный маскот Pushok, кнопка подключения с мягким свечением, блок Smart Routing.
- Секретная конфигурация WireGuard скрыта в сворачиваемом разделе.
- Сохранены ранее созданные Android-интеграции и CI.

**Внимание:** интерфейс и тесты проверены на уровне исходников. Flutter SDK в окружении отсутствует; APK и VPN на устройстве не проверялись.
