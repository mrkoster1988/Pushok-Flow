# Pushok Flow: сборка и выпуск Android

1. Создать отдельный репозиторий `mrkoster1988/Pushok-Flow` в GitHub (если отсутствует).
2. Загрузить все файлы этого архива **в корень** репозитория, включая скрытую папку `.github`.
3. В Actions запустить `Android debug APK (unverified on device)` → Run workflow.
4. Убедиться, что проходят `flutter pub get`, `flutter analyze`, `flutter test`, `:app:compileDebugKotlin`, сборка APK и `verify_android_apk.py`.
5. Скачать артефакт `pushok-flow-debug-apk`, проверить SHA-256 по диагностическому артефакту.
6. На тестовом Android вручную импортировать WireGuard-профиль и выдать системное разрешение VPN; проверить DNS/IPv4/IPv6, IP туннеля и IP приложений-исключений.
7. Не публиковать реальные приватные ключи, VPN-конфигурации или персональные данные в Issues/логи.

**Нельзя считать готовым:** APK без успешной CI-сборки; маршрутизацию без проверки на реальном Android; работу банков без теста конкретного приложения.

**Дизайн:** эталон — три утверждённых пользователем макета: тёмно-синий фон, бирюзово-фиолетовые волны, неоновая круглая кнопка, фирменный рыжий маскот, светящиеся карточки и контурные иконки.
