# Pushok Flow v0.5.0 — исходный код

## Добавлено
- Android Keystore AES-256-GCM для локального шифрования WireGuard-профиля (не сохраняется автоматически).
- Явное сохранение, открытие и удаление профиля из Flutter.
- Возврат безопасного кода последней ошибки в диагностике, без ключей и конфигураций.
- Идемпотентная генерация Android-проекта Flutter с нативным WireGuard-мостом.
- GitHub Actions для debug APK (после публикации в GitHub).

## Ограничения
- Не собран и не испытан APK в этом окружении. GitHub workflow не выполнялся.
- Защищённый профиль не подключается автоматически после перезапуска. Это осознанное ограничение текущей версии.
- Конфигурация после открытия видна на экране редактирования; исключить скриншоты и clipboard предстоит отдельно.
- Android Auto Backup отключается установочным скриптом (`allowBackup=false`) для защиты зашифрованного профиля от нерасшифровываемого восстановления. Проверить итоговый merged manifest перед выпуском.
- Подписанная публикация, foreground service, reconnect, реальные сетевые тесты и полноценный Pushok ИИ ещё впереди.
- CI собирает debug APK; он **не** готов для публичного распространения.
