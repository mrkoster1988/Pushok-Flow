# Pushok Flow v0.44.0 — фоновая загрузка и аккаунт MTProxy

## Состояние

Подготавливается один универсальный Android APK. Ссылки на успешные проверки точного исходника, постоянную подпись и публичный канал добавляются после их фактического выполнения.

## Загрузка обновления после сворачивания

Пользователь сообщил, что загрузка прекращается при переходе в другое окно. Раньше ручная кнопка выполняла передачу в очереди обычного процесса приложения. Долговечная фоновая задача не владела этой передачей с момента нажатия. Кроме того, индикатор скрытого экрана переставал опрашивать состояние, поэтому его неподвижность сама по себе не доказывала остановку сети.

Теперь ручная загрузка сразу сохраняется как отдельная задача WorkManager. Она не отменяется настройкой автообновления и не принадлежит Activity. Перед открытием потока APK задача запрашивает foreground-выполнение с уведомлением о загрузке; разрешение уведомлений Android 13+ запрашивается отдельно, а отказ не отменяет загрузку.

После потери сети или остановки задачи сохраняется частичный файл для проверяемой докачки того же APK. Повторный запрос не заменяет уже работающую задачу того же файла. При возврате на экран Flow показывает актуальное состояние. Перед установкой сохраняются проверки размера, SHA-256, пакета, версии, архитектур и постоянного сертификата.

Android может откладывать выполнение из-за системных ограничений, квот, принудительной остановки или настроек производителя. Отказ в запуске foreground-службы обрабатывается без падения: остаётся ограниченная по времени задача планировщика и сохранённая докачка. Непрерывная работа после принудительной остановки не обещается. Проверка на конкретном телефоне ещё необходима.

## Профиль существующего аккаунта

Карточка аккаунта получает действительные имя, роль, признак подтверждения телефона и баланс MTProxy после явного разрешения в существующем кабинете. Новый пользователь Flow не создаётся. Используется отдельная сессия только для чтения профиля и баланса, действующая 12 часов; административная сессия кабинета в APK не передаётся.

Flow показывает код, открывает существующий Telegram-бот и завершает вход после возврата. Отказ, истечение запроса, недоступный сервер и неподтверждённый серверный выход имеют отдельные сообщения. При сетевом сбое сохраняется последний профиль с отметкой устаревших данных. Денежные суммы отображаются целочисленно, включая отрицательный баланс.

Требуется серверная часть MTProxy v1.121 с совместимым `/api/v1/flow`. При старом сервере Flow сообщает об отсутствии поддержки; обычный переход в существующий кабинет остаётся доступен. [Сценарий, права и хранение данных](ACCOUNT.md).

## Приёмка на Android

Проверить обновление поверх прежней подписанной версии без удаления приложения, сохранение профилей и настроек, загрузку при переключении на другое приложение и выключении экрана, отображение уведомления и докачку после временной потери сети. Для аккаунта — вход через существующий Telegram, совпадение кода и явное согласие, корректный профиль и баланс, выход и повторный вход. Публикация и автоматические проверки не заменяют приёмку на физическом телефоне.
