# Pushok Flow v0.43.0 — существующий аккаунт MTProxy

## Состояние

Опубликован один универсальный APK для Android. Успешные CI точного исходного коммита, постоянная подпись и независимые публичные проверки подтверждены ниже.

## Исправленный сценарий

Пользователь сообщил, что регистрация уже работает в проекте MTProxy Pushok, а карточка Flow направляет в неразработанный сценарий `@pushok_app`. Запись `43004.mp4` показывает установленную v0.41.0, кнопку «Открыть Pushok» и пустую страницу `t.me/pushok_app` в Chrome. Видео не показывает вход в кабинет.

В профиле Flow теперь есть **«Открыть кабинет MTProxy»**. Приложение сначала передаёт Android нативную ссылку `tg://resolve?domain=mtproxy_pushok_bot`. Если Telegram не установлен или переход недоступен, используется существующий HTTPS-кабинет `https://pushok.shop/`. Имя бота проверено по публичной конфигурации работающего сервера: [проверка](development-checks/mtproxy-account-v043.json).

Общая ссылка экосистемы **`@pushok_app`** сохранена отдельной кнопкой и также сначала открывается через Telegram. Ложное обещание готовой регистрации, оплаты и подписки по общей ссылке удалено. В разделе подписок действие называется «Кабинет MTProxy»; справка объясняет, что серверы Flow добавляются по ссылке провайдера.

MTProxy уже проверяет подписанные данные Telegram и повторно использует пользователя по уникальному Telegram ID. Новая база пользователей и отдельная регистрация Flow не создаются. Передача серверной сессии кабинета в APK в этот выпуск не входит, поэтому открытие кабинета не объявляется входом внутри Flow. Аккаунт MTProxy сам по себе не предоставляет VLESS/WireGuard-подписку.

## Один Android APK

Candidate workflow собирает только универсальный `app-release.apk`. Проверки исходного коммита, пакета, версии, состава нативных библиотек, подписи и выравнивания сохранены. Другие платформы и отдельные ABI-варианты отложены по указанию пользователя.

## Ошибка обновления на записи

Видео также показывает неудачную загрузку v0.42.0 в установленной v0.41.0. Выбор универсального APK этой версией поддерживается; опубликованный файл ранее полностью скачан и проверен. По общему сообщению `UPDATE_DOWNLOAD_FAILED` нельзя установить причину сбоя на телефоне. Этот выпуск не объявляет сетевую ошибку устранённой без подтверждения на устройстве.

## Приёмка на Android

После установки проверить открытие кабинета из профиля при установленном Telegram, запасной переход в браузер при отсутствии обработчика, использование существующего аккаунта и отдельную общую ссылку `@pushok_app`. Реальный вход, загрузка APK по сети телефона и сохранение данных при обновлении требуют проверки на устройстве пользователя.

На телефоне ещё нужно подтвердить установку с сохранением данных, переход в существующий кабинет MTProxy через Telegram и веб-резерв, а также загрузку обновления. Этот выпуск не реализует обмен сессией авторизации между кабинетом и Flow. Ошибка скачивания на телефоне, показанная в записи пользователя, не объявляется исправленной. Публичные проверки загрузки из среды выпуска не заменяют эти испытания.
