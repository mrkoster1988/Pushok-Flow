# Pushok Flow v0.23.0 — кнопка сохранения над системной панелью

Версия приложения: `0.23.0+23`.

## Что показала запись v0.22.0

Подтверждены запуск установленной v0.22.0, переходы по вкладкам, выбор двух исключений, оценка Pushok ИИ и очистка памяти. При подключении без профиля открывается редактор. Ошибка некорректного профиля остаётся в редакторе и не переносится в «Маршруты».

Найдены два недостатка: системная панель Android перекрывает нижнюю часть кнопки сохранения; подсказка о формате не объясняет, почему одна строка UUID не подходит для WireGuard. Успешное сохранение полного профиля, соединение Flow VPN и маршруты трафика на записи не показаны. Значение идентификатора из записи не включено в код, тесты и документацию.

## Изменения

- Содержимое редактора учитывает нижнюю системную область Android. Кнопки «Сохранить профиль» и «Сохранить и подключить» должны полностью размещаться над панелью навигации.
- Отступ открытой клавиатуры учитывается отдельно; раскрытый профиль можно прокрутить на компактном экране.
- Подсказка прямо указывает требуемый формат: полный текст WireGuard `.conf` с разделами `[Interface]` и `[Peer]`.
- Вставка отдельного UUID показывает понятное объяснение до обращения к Android-мосту. Такой ввод не заменяет уже открытый корректный черновик при вставке.

Нижний отступ добавлен внутри существующего оформления редактора. Неоновая рамка и цвета сохранены.

## Повторная проверка на телефоне

1. Открыть редактор с главной и из «Серверов»: нижняя кнопка должна полностью находиться над системными кнопками Android.
2. Нажать «Подключить» без профиля и проверить расположение «Сохранить и подключить».
3. Проверить подсказку для UUID. Для проверки VPN использовать полный рабочий WireGuard-профиль, а не отдельный идентификатор.
4. Вставить полный `.conf`, сохранить и подключиться, разрешив системный VPN. Затем проверить подключение после перезапуска и маршруты выбранных приложений.

Конфигурации и приватные ключи в отчёт и запись экрана не включаются.
