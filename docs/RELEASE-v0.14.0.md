# Pushok Flow v0.14.0 — CI reliability

**Что изменилось:** в Android CI исправлено маскирование ошибок в командах, работающих через `tee`; добавлен запуск исполняемых Kotlin-тестов маршрутизации и проверка Android SDK перед сборкой. Номер версии: `0.14.0+14`.

**Что подтверждено:** тесты исходников и Kotlin-маршрутизации при наличии Kotlin CLI.

**Что не подтверждено:** компиляция Android/Flutter, наличие APK, работа WireGuard и исключений на физическом устройстве.

**Как проверить после публикации:** открыть Actions → Android debug APK → Run workflow, дождаться успешного `flutter build apk --debug`, скачать артефакт и проверить подключение на устройстве.
