## Способ подписи

Для локальной подписи использована **существующая личная резервная копия** исходного сертификата. Закрытый ключ и пароли не добавлялись ни в репозиторий, ни в сборочные артефакты, ни в публичный выпуск.

После подписи был сформирован публичный бинарный delta-документ `release-staging/v0.58.0.json`, который восстанавливает точные байты подписанного APK из проверенного CI-артефакта. В автоматической публикации повторно проверены содержимое, постоянный сертификат и манифест обновлений.
