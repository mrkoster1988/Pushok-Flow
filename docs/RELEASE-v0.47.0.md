# Pushok Flow v0.47.0 — VLESS при смене сети

## Состояние

Подготавливается один универсальный APK для Android с versionCode 47.
Публикация допускается после CI точного исходного коммита, постоянной подписи
и проверки готового APK. Этот документ будет дополнен результатами выпуска.

## Переключение Wi-Fi и мобильного интернета

Исправлено назначение DNS и новых исходящих соединений VLESS при смене
физической сети. Раньше адрес DNS выбирался при включении и мог остаться
недоступным после отключения Wi-Fi. Теперь разрешение имени сервера и новые
сокеты используют общий выбор физической сети Android; каждая новая операция
захватывает актуальный снимок.

Ядро и системный TUN сохраняются в рамках того же пользовательского подключения.
При отсутствии сети Flow ожидает её появления и сохраняет возможность явно
отключиться. Возврат сети обновляет назначение для новых соединений. Уже
установленные TCP-сеансы не переносятся между сетями; удалённый транспорт и
приложения могут открывать их повторно.

При выборе сети учитываются доступность интернета по capabilities, результаты
проверки Android и тарификация. Подтверждённая сеть предпочтительнее; при
одинаковом качестве сохраняется текущий выбор. Отсутствие `VALIDATED` само по
себе не запрещает единственную доступную сеть: системная проверка Android может
быть заблокирована независимо от доступности сервера Flow. Явная captive portal
не выбирается для подключения.

## DNS и ограничения ресурсов

Имя VLESS-сервера разрешает системный механизм Android для выбранной сети.
Он учитывает Private DNS и возвращает адреса IPv4/IPv6. Исходные TLS/SNI,
WebSocket Host, gRPC authority и сохранённый профиль не переписываются.

Постоянный DNS-посредник внутри отдельного процесса Xray принимает только
`A`/`AAAA` для имени активного сервера. Ограничены размеры запросов, очередь,
количество потоков и время ожидания. При смене сети и отключении устаревшие
результаты отбрасываются. Зависший системный вызов не освобождает слот до
реального завершения и не приводит к неограниченному созданию потоков.

Глобальный DNS resolver ядра устанавливается один раз. При смене сети не
вызывается последовательность остановки/перезапуска ядра и повторной замены
resolver. [Техническое устройство и первоисточники](XRAY-NETWORK-HANDOVER.md).

## Статус и отключение

Flow различает локальную готовность передачи и удержание подключения. При
потере сети интерфейс показывает ожидание и скрывает устаревшие показатели.
STOP остаётся доступен; изменение профиля, маршрутов и установка обновления
учитывают удерживаемое подключение даже при отсутствии локального UP.

Отключение инвалидирует текущее сетевое назначение до завершения native cleanup.
Запоздавший callback или DNS-ответ не запускает новое подключение. Перезапуск
приложения или сервиса по старому Intent также не включает соединение.

## Проверки

Локально прошли **269 тестов Python, 324 теста Flutter и 28 исполняемых наборов
Kotlin**. Flutter-анализатор не обнаружил замечаний. После последнего изменения
совместимости NIO отдельно перепроверены оба DNS-набора на окончательных исходниках.
CI, подпись и публичная загрузка будут записаны после завершения этих этапов.

Исполняемые проверки охватывают разбор DNS, разрешённое имя, настоящие локальные
UDP/TCP-сокеты, таймауты, старые результаты, выбор сети, владение подключением и
доступность STOP. Для Android observer исполняется production-класс с управляемыми
подставными Android API: проверены новые availability-only события Android 7,
потеря сети во время чтения metadata и приоритет callbacks над устаревшими getters.
На экранах шириной 320/360 проверено отсутствие переполнения новой надписи.
Android-сборка проверяет обязательное разрешение `CHANGE_NETWORK_STATE` для
физического binding.

## Проверка на телефоне

Остаются фактические переходы Wi-Fi → мобильный интернет и обратно, временная
потеря обеих сетей, STOP во время ожидания, частный DNS и IPv6 на конкретном
устройстве. Отдельно сохраняются ранее обозначенные проверки исходного
пользовательского QR, полного входа через существующий кабинет MTProxy и
фонового обновления. Результаты сборки не объявляются результатами этих
испытаний.
