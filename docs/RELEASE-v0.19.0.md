# Pushok Flow v0.19.0 — дизайнерское выравнивание

- Внедрён эталон Flow по трём утверждённым изображениям от 20.11.2026.
- Неоновый фон с волнами, карточки и главная круглая кнопка в цветах Flow.
- На главном экране размещены оригинальный маскот, статус подключения, быстрые переходы и маршрутизация.
- Сохранены реальные действия подключения WireGuard, настройки исключений, Pushok ИИ и локальное хранение профиля.
- APK и Flutter widget-тесты требуют Flutter SDK; до фактического запуска успешную сборку не заявлять.
