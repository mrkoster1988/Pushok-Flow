# Pushok Flow 0.36.0 — VLESS из 3x-ui

Подготовка: 22.11.2026 (Москва). Версия приложения **0.36.0+36**, пакет `shop.pushok.flow`. До завершения проверок и публикации этот документ описывает исходный код следующего выпуска.

## Что меняется

- В существующем редакторе добавлены VLESS-ссылка, QR камеры, QR из изображения и текстовый файл с одной ссылкой. Поддерживаются TCP/Raw с TLS или REALITY, включая Vision.
- Редактор и список профилей получили общие названия для WireGuard и VLESS. Подробности форматов находятся под ⓘ. Сохранение и подключение остаются отдельными действиями.
- Новый Android-движок Xray использует системный TUN. Он работает в отдельном приватном процессе, чтобы его Go runtime не конфликтовал с WireGuard. Один общий контроллер приложения разрешает только одно активное подключение.
- Пользовательские исключения приложений применяются перед созданием нового туннеля. Недоступные пакеты и неопределённое состояние службы останавливают изменение настроек.
- Существующий зашифрованный каталог, выбранный профиль и настройки не мигрируют в новую схему. WireGuard-профили остаются доступны.
- Диагностика различает протоколы и не показывает показатели рукопожатия WireGuard для VLESS. Успешный запуск локального TUN не выдаётся за проверку удалённого сервера.

[Пользовательская инструкция и поддерживаемые варианты](3X-UI.md).

## Проверки

В проверках используются только тестовые ссылки. Проверяются корректный разбор и отказ на неподдерживаемые параметры, отсутствие секретов в метаданных и ошибках, сохранность смешанного каталога профилей, общий порядок подключения/отключения, импорт QR и сохранность черновика. Полный результат CI и точные параметры опубликованного APK добавляются после фактического завершения сборки.

Независимо выполнен `testXray` официального Linux libXray 26.11.9 над четырьмя конфигурациями, созданными настоящим `XrayConfig.build`: TLS и REALITY, каждый с Vision и без flow. Все четыре приняты; отрицательная конфигурация отклонена, `getXrayState` после проверок подтвердил `running=false`. [Наблюдения и хеши проверенных исходников](development-checks/vless-core-config.json). Это проверка структуры конфигураций тем же ядром, а не запуск Android-туннеля или сетевое испытание.

## Доставка и границы

Для нового сетевого движка требуется APK с прежним постоянным сертификатом. Обычный путь — **Профиль → Версия и обновления → Проверить обновления → Скачать → Установить обновление**. Удаление опубликованной подписанной версии не требуется.

Полная поддержка любых конфигураций 3x-ui не заявляется. В этот выпуск не входят VMess, Trojan, Shadowsocks, WebSocket, gRPC, XHTTP и подписки. Подключение конкретного пользователя, сохранность данных при обновлении на физическом Android, DNS, IPv6 и прямые маршруты требуют проверки на устройстве. Ранее зафиксированное предупреждение Play Protect остаётся отдельной задачей.
