# Pushok Flow v0.12.0 — безопасность жизненного цикла и аудит обновлений

- При уничтожении Android Activity во время системного запроса разрешения VPN незавершённый MethodChannel вызов завершается кодом `VPN_REQUEST_INTERRUPTED`; пользователь может повторить подключение. Уже поднятый туннель при этом **не отключается**.
- Запрещён второй вызов подключения во время операции запуска/остановки.
- Аудит обновлений назначен на 21:00 Europe/Helsinki с двумя UTC cron-триггерами и DST-проверкой. Время запуска GitHub Actions не гарантируется; при задержке больше часа запуск может быть пропущен. `workflow_dispatch` доступен вручную.
- Renovate использует Europe/Helsinki и не сливает обновления WireGuard автоматически.
- Код не загружает пользовательские WireGuard-ключи в Pushok ИИ.

## Границы проверки

Python unittest и тесты расписания не доказывают, что Kotlin компилируется. Здесь **нет подтверждённого APK**, нет проверки на Android или iOS. CI начнёт работать лишь после публикации в репозитории и включения Actions.
