# Pushok Flow v0.22.0 — настройка WireGuard и Android debug APK

Мобильное приложение Pushok Flow: WireGuard, выборочный прямой трафик приложений Android, фирменный неоновый интерфейс и локальная основа Pushok ИИ.

**Состояние:** APK v0.22.0 успешно собран и проверен в GitHub Actions; испытание этой версии на телефоне ещё предстоит. Запись v0.21.0 подтверждает запуск, работу вкладок, списка приложений и локальной обратной связи. Реальное VPN-подключение и маршруты трафика пока **не подтверждены**.

- Исходники: [`69dd9ff`](https://github.com/mrkoster1988/Pushok-Flow/commit/69dd9ffd94d144fb3398da1af8e96c03c8292a94), версия `0.22.0+22`.
- [Успешная Android-сборка и APK](https://github.com/mrkoster1988/Pushok-Flow/actions/runs/44817781185).
- [Успешные проверки исходников и Flutter](https://github.com/mrkoster1988/Pushok-Flow/actions/runs/44817781187).
- Проверены: 100 Python-тестов, исполняемые Kotlin-тесты маршрутов и диагностики, анализ Dart, 23 Flutter-теста, компиляция Android и итоговый манифест APK.
- APK: `app-debug.apk`, 169 003 196 байт; SHA-256: `520eb1656d35ec9c857f424d2f1d17c1fa2b6c407ffc78c8a99bdf53f291524c`.

Артефакт `pushok-flow-debug-apk` содержит APK; `pushok-flow-android-build-diagnostics` содержит журналы и `apk-sha256.txt`. Срок хранения в Actions — 7 дней. Это debug-сборка для тестирования. Порядок воспроизведения и проверки на телефоне: [docs/BUILD-AND-RELEASE.md](docs/BUILD-AND-RELEASE.md).

**Установка после v0.21.0:** сертификаты этих двух debug APK различаются, поэтому обновление поверх старой версии невозможно. Перед удалением приложения сохраните исходную конфигурацию WireGuard вне Pushok Flow: переустановка очистит локальный профиль, исключения и оценки Pushok ИИ. Подробности и отпечатки сертификатов приведены в инструкции по сборке.

## Изменения v0.22.0

- Подключение без профиля открывает редактор с действием «Сохранить и подключить».
- Кнопка «Вставить» сохраняет переносы строк конфигурации; скрытый текст защищён от случайного редактирования.
- Сохранённый защищённый профиль доступен для подключения после перезапуска приложения.
- Ошибки профиля остаются в редакторе и не появляются на вкладке «Маршруты».
- При возврате из фона обновляется реальное состояние туннеля; повторные операции блокируются на время выполнения.

Подробности: [docs/RELEASE-v0.22.0.md](docs/RELEASE-v0.22.0.md).

## Проверки

CI использует Flutter `3.50.0`, Material UI `1.11.1`, Java 17 и WireGuard `1.0.20260102`. Локально нужны Flutter и Android SDK; для самостоятельных Kotlin-проверок — `kotlinc`.

```bash
python -m unittest discover -s tests -v
bash tools/check_kotlin_routing.sh
flutter pub get
flutter analyze lib test
flutter test
```

Сборка APK: **Actions → Android debug APK (unverified on device) → Run workflow**. При сбое открыть артефакт `pushok-flow-android-build-diagnostics`.

## Безопасность

Никогда не публикуйте WireGuard PrivateKey, токены Pushok ID и реальные пользовательские конфигурации. Любые маршруты банков требуют проверки на устройстве. На iOS исключение произвольных приложений недоступно в обычном потребительском VPN.

## Визуальный стандарт

Согласованные неоновые бирюзово-фиолетовые макеты Pushok Flow; упрощение внешнего вида не допускается. Детали: [docs/DESIGN-SYSTEM.md](docs/DESIGN-SYSTEM.md).

## Обновления

Предусмотрен аудит зависимостей в 21:00 по Хельсинки, но расписание GitHub Actions может запускаться с задержкой. Обновления WireGuard не сливаются автоматически без проверки.
